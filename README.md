# CodeAlpha Stock Trading Platform

A Java console simulation of a stock market and a user's portfolio. It does not connect to a real exchange or place real trades.

## Features
- View a sample market with simulated INR prices.
- Buy and sell shares while enforcing cash and holdings limits.
- Track cash, holdings, total portfolio value, and transaction history.
- Manually simulate price changes to see portfolio value change.

## Requirements
- Java 17 or newer

## Run
```bash
javac src/StockTradingPlatform.java
java -cp src StockTradingPlatform
```

## Concepts used
Object-oriented programming, maps, lists, methods, formatted output, and input validation.
